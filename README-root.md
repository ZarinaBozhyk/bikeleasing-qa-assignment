# Bikeleasing – QA Engineer Tasks

Solutions for the two QA Engineer tasks.

| Folder | Task | Content |
| --- | --- | --- |
| [task-1](task-1/README-task1.md) | BDD and feature files | Gherkin feature files for bike insurance claims, coverage matrix, clarification questions |
| [task-2](task-2/README.md) | Gradle, Kotlin and Serenity | Runnable UI and API tests with a Serenity report |

## Quick start (Task 2)

```bash
cd task-2
./gradlew clean test
```

The Serenity report is generated in `task-2/target/site/serenity/index.html`.
Prerequisites and details are in the [Task 2 README](task-2/README.md).
